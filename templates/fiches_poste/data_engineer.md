# Job Description: Data Engineer

## General information
- **Title:** Data Engineer
- **Department:** Data Platform
- **Reports to:** Head of Data
- **Location:** Paris / Hybrid (3 days office, 2 remote)
- **Employment type:** Permanent

## Main mission
Design, develop, and maintain the data pipelines that power the company's data products (analytics, machine learning, and reporting). Ensure data flow quality, reliability, and performance at scale.

## Responsibilities
- Design and develop robust, scalable ETL/ELT pipelines
- Model data in the data warehouse (BigQuery)
- Set up and maintain workflow orchestration (Airflow)
- Ensure data quality through testing, monitoring, and alerting
- Collaborate with Data Analysts and Data Scientists to understand requirements
- Document pipelines and data models
- Participate in code reviews and team technical decisions
- Contribute to continuous improvement of the data platform

## Stack technique
- **Cloud :** Google Cloud Platform (BigQuery, Cloud Storage, Dataflow, Pub/Sub)
- **Orchestration :** Apache Airflow / Cloud Composer
- **Transformation :** dbt
- **Langages :** Python, SQL
- **CI/CD :** GitHub Actions, Terraform
- **Monitoring :** Datadog, Monte Carlo

## Requirements
- 3+ years of Data Engineering experience
- Strong advanced SQL and Python skills
- Experience with a cloud provider (GCP preferred)
- Knowledge of data modeling principles (Kimball, Data Vault)
- Good understanding of data quality challenges
- Independence, rigor, and teamwork

## 90-day goals
1. **30 days:** Understand the data architecture and deliver a first pipeline
2. **60 days:** Own a data domain independently
3. **90 days:** Propose platform improvements
