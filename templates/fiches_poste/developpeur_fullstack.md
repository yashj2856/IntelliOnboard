# Job Description: Fullstack Developer

## General information
- **Title:** Fullstack Developer
- **Department:** Engineering
- **Reports to:** Engineering Manager
- **Location:** Paris / Hybrid
- **Employment type:** Permanent

## Main mission
Develop and maintain the company's web applications, from frontend to backend. Contribute to code quality, technical architecture, and user experience.

## Responsibilities
- Develop frontend (React/Next.js) and backend (Node.js/Python) features
- Participate in technical design and architecture decisions
- Write unit and integration tests
- Participate in code reviews
- Collaborate with Product Managers and Designers
- Maintain and improve CI/CD pipelines
- Document code and technical decisions

## Stack technique
- **Frontend :** React, Next.js, TypeScript, Tailwind CSS
- **Backend :** Node.js, Python (FastAPI)
- **Base de données :** PostgreSQL, Redis
- **Infrastructure :** Vercel, Docker, GitHub Actions
- **Monitoring :** Sentry, Datadog

## Requirements
- 3+ years of fullstack web development experience
- Strong React and backend framework skills
- TypeScript experience
- UX awareness and attention to detail
- Experience working in an agile team

## 90-day goals
1. **30 days:** Complete technical onboarding and merge a first bug fix
2. **60 days:** Deliver a feature end to end
3. **90 days:** Work independently on the main codebase
